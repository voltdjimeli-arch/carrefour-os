# Carrefour OS

Documentation de conception pour un projet de systèmes d’exploitation qui vise à simuler un carrefour multivoies et multibranches.

Le modèle est en cours d’élaboration. Il s’appuie sur des automates temporisés, un graphe de conflits entre trajectoires et un ordonnanceur central. Il doit pouvoir représenter les zones partagées, les priorités, les convois indivisibles, les véhicules d’urgence, les temps d’attente et les interblocages.
